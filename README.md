Резонансный фильтр
Что это
Ассоциативная память на основе логических операций. Хранит и распознаёт образы без операций умножения, без GPU, без градиентного обучения.

Как устроена
Нить — строка из 8192 нейронов, каждый хранит целое число от -128 до 127.

Слово — отпечаток длиной 128 нейронов:

16 нейронов со значением +1 (нагрев).

16 нейронов со значением -1 (охлаждение).

96 нейронов со значением 0 (пустота).

Слова размещаются с шагом 64 нейрона (50% нахлест).

Чётные слова занимают только чётные позиции внутри своей зоны. Нечётные — только нечётные. Поэтому соседние слова не пересекаются по активным нейронам.

Как обучается
Каждое слово один раз записывается в нить: +1 прибавляется к нейронам нагрева, -1 вычитается из нейронов охлаждения.

Обучение без обратного распространения ошибки. Один проход. Без градиентов.

Как узнаёт
Входное слово сравнивается со всеми зонами нити. Для каждой зоны подсчитываются совпадения знаков: если знак нейрона нити совпадает со знаком маски и оба не ноль — плюс одно очко.

Зона с максимальным счётом — ответ.

Результат
63 слова на 8192 нейронах. 100% узнаваемость. Один проход обучения.

Отличия от нейросетей
Нет умножения.

Нет GPU.

Работает на процессоре.

Обучение мгновенное.

Память линейна и прозрачна.
